# 候选形态对照

三条准入条件出自意图仓的 [qtgame-love 意图](https://github.com/quanttide/quanttide-intention-of-founder/blob/main/qtgame-love/index.md)：**视角代入**（不给全知信息）、**决策约束**（选择落在主角会做的范围内）、**事业爱情双主线**。它们是筛子，不是某种形态的特性——下面逐个形态看它怎么过这三条。过不了的出局，不靠后期补。

## 1. 互动视觉小说（分支叙事）

- **代入**：镜头锁死主角第一视角。陆知微为什么走进「沙发咖啡」、她心里那句「好久不见」憋了多久，玩家和林远亭一样看不见——看见了就是全知，正是要防的。
- **约束**：选项由剧本写死，玩家只能在「主角会犹豫的几种说法」里挑，不给最优解按钮。选错的代价当场兑现（冷场、错过窗口），读档重试要有代价。
- **双主线**：事业节点（论坛演讲前夜、投资人会面）与关系节点交替成章，共用同一份日程，不是恋爱之外挂个背景板。
- **风险**：最容易退化成「读者点下一步」。判断信号是选项是否自由到可以试错——能随便试，就还是全知读者。

## 2. 事业经营数值（职场线）

- **代入**：扮演林远亭，钱、档期、演讲稿都从现实里拿。数字拿不到就是拿不到，跟主角一样没有后台信息。
- **约束**：**事业与爱情抢同一张日程表**——今天去见投资人还是去见她，是同一资源上的取舍。这条形态对「决策约束」的回答最硬：不用限制玩家的习惯，资源本身就限制了。
- **双主线**：天然双主线，两条线各有进度与代价。
- **风险**：数值容易盖过人物；与 `qtgame-tycoon` 同源（`engine/` 纯逻辑可在 Node 跑模拟），要防同质化成「换皮串串摊」。

## 3. 舆论场模拟（校园线）

- **代入**：信息只以帖子、截图、热搜的形式到达。窦逸和林栀在论坛里看对方，玩家也只看到流出来的东西——全校都在吃瓜，当事人却在各自宿舍回味那张照片。
- **约束**：发言即留痕，热搜不可撤回。要面子的人不敢乱说话，这条约束贴着主角的性格长，不是硬加的规则。
- **双主线**：新传/学术的事业线与感情线共用同一个曝光资源，涨粉与升温互相挤占。
- **风险**：机制绑定校园论坛设定，三部曲里只有校园线撑得起，素材复用面最窄。

## 4. 重生循环重开（重生线）

- **代入**：玩家继承记忆，继承不了信息差。前世知道她会去海边，但不知道这一世她为什么去——「已知结局再走一遍，该来的困难一样不会少」。
- **约束**：重开有成本（关系归零），玩家被迫像主角一样谨慎开口，而不是无限试错刷好感。
- **双主线**：前世的创业失败与错过她一起回炉，事业与爱情在同一轮里同时重来。
- **风险**：分支与存档状态最复杂；「重开理由」必须来自剧情而不是数值，否则就是roguelite 套皮。

## 5. LLM 对手戏

- **代入**：对方是活的。玩家按主角的处境说话，台词被按角色语气接住，无法靠预设选项白嫖。
- **约束**：LLM 只按角色设定与已知信息回应，玩家不能用话术刷出主角不会得到的回应。
- **双主线**：事业线的对手（投资人、竞争者）与感情线可以共用同一套对话能力。
- **风险**：质量不可控、依赖外部模型、成本最高。放后期，不当地基。

## 组合：形态 1 + 2（首选）

两种形态不是并列候选，是同一件事的两面：**分支叙事承载爱情线，经营数值承载事业线，两者互为因果**。

- **耦合机制**：男女主的心理与情感状态是两条线的共同输入——心理与情感的变化推动事业的变化，事业的受挫又反过来压回开口的时机。这条因果是**剧情暗线**：不给玩家看公式，只让他看见结果。
- **举例**：论坛演讲前夜失眠，改不改稿取决于白天那件事说没说开；融资失利之后，回到她面前开不了口。反向也成立——敢不敢在台上讲那句，取决于这件事有没有说开。
- **为什么它同时过三条准入**：玩家和主角一样事后才明白因果（代入）；两条线抢同一张日程表（约束）；两条线不是并列进度条，而是互为因果（双主线）。
- **风险**：暗线做成明线（显示「情感值 → 事业值」的换算）代入就没了；耦合太隐蔽，玩家会以为两条线各跑各的。验证时看玩家复盘能不能说出「我因为 X 才……」的因果句。

## 怎么用这张表

- **先做形态 1 + 2 的组合原型**，其余形态并行起单文件原型，每个只验一条最担心的假设。验证口径与失败判据见意图仓。
- **共享资产**：角色卡、场景、台词、时间线在形态间复用——换形态不废素材，这是不锁死单一形态的前提。
- **选择发生在验证之后**，不在写原型之前。
